# Guía de Contribución

Gracias por participar en el desarrollo de BrandFit.

---

## Opciones de Contribución

### 1. Reporte de Errores
- Revisa los reportes existentes para comprobar si el problema ya fue registrado.
- Si se trata de un nuevo error, abre un reporte detallando:
  - Descripción del problema.
  - Pasos para reproducirlo.
  - Comportamiento observado frente al esperado.
  - Entorno y versiones utilizadas.

### 2. Propuestas de Mejora
- Plantea nuevas ideas o ajustes para los módulos del flujo mediante un ticket con la etiqueta de propuesta.
- Describe el objetivo técnico o funcional y el valor agregado para la herramienta.

### 3. Envío de Código
1. Crea una bifurcación (fork) del repositorio.
2. Clona tu bifurcación de manera local:
   ```bash
   git clone https://github.com/TU_USUARIO/BrandFit.git
   cd BrandFit
   ```
3. Crea una rama de trabajo:
   ```bash
   git checkout -b feat/nombre-funcionalidad
   ```
4. Implementa los cambios siguiendo estándares de código limpio.
5. Registra los cambios utilizando la convención de commits (Conventional Commits).
6. Sube los cambios a tu bifurcación:
   ```bash
   git push origin feat/nombre-funcionalidad
   ```
7. Abre un Pull Request dirigido a la rama principal (`main`).

---

## Lineamientos

- Mantén las confirmaciones (commits) atómicas y con mensajes descriptivos.
- Cumple con las pautas de interacción establecidas en el [Código de Conducta](CODE_OF_CONDUCT.md).
