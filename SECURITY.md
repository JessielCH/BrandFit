# Política de Seguridad

## Versiones con Soporte

BrandFit está actualmente en fase inicial de prototipo.

| Versión | Estado de Soporte |
| ------- | ----------------- |
| 0.1.x   | Soportada         |
| < 0.1   | No soportada      |

---

## Notificación de Vulnerabilidades

Si identificas un problema o fallo de seguridad:

1. No divulgues la vulnerabilidad mediante un reporte público.
2. Envía un informe detallado a través de los canales privados del mantenedor o mediante una alerta de seguridad (Security Advisory) en GitHub.
3. Proporciona los pasos necesarios para reproducir el fallo y una evaluación de impacto si es posible.

Se valorará la notificación responsable para permitir la corrección antes de cualquier anuncio público.
